# Views on pages

A View widget shows data from an app in a layout you choose. The app decides
which data and fields it offers; a view does not copy those items.

1. Open a page and choose **Edit page → Add widget → Built in → View**.
2. Open the widget's **Settings** and choose an app and its data.
3. Use **Show as** to pick List, Table, Board or Calendar. Available layouts
   depend on the fields the app offers: boards need a choice field, and
   calendars need a date field.
4. Choose **Sort by** and Ascending or Descending. Use **Group by** where
   offered, **Columns from** for board lanes, or **Date** for a calendar.
5. Set **Keyword**, or enable **Follow page focus**, then finish editing.
   A typed keyword replaces the page focus for that widget.

To-do offers task data, Notes offers notes and Bookmarks offers bookmarks.
You can place several views on a page to see the same items in different ways.
Click an item to open it. Tables support sorting; calendars show a month grid
with month navigation. Items need a date in the selected field to appear there.

If an app supplies a move action, drag a board card between columns to update
it. You can also focus the card handle and use arrow keys. To-do's own board
and matrix layouts support moves too. A board without a declared move action
is for viewing; changing its layout does not add new app actions.

For selection actions on supported lists, see
[Select many items](first-steps.md#select-many-items).
