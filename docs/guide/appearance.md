# Appearance

Open **Settings → Appearance**.

- **Mode:** System, Light or Dark. Set per device.
- **Themes:** pick the theme for this device. **More themes** lists the themes
  that come with the app (Forest, Nord, Paper, Rose, Terminal); install one to
  use it.
- **Install a theme:** choose a `.theme.json` file. Installing a theme with the
  same id updates it. Installed themes sync to all your devices.
- **App icons:** **Monochrome** for quiet outlines, or **App colors** to use
  each app's color across navigation, widgets and app pages. Set per device.
- **Customize workspace:** choose and reorder the pinned apps in the left rail,
  Companion widgets and quick actions. Set per space.

A theme is only colours and a font choice, with no code, so it installs without
a permission review. To make one, see [making a theme](../develop/themes.md).
