      Google Drive

      Optional. Lets your phone sync while this computer is asleep. Only this app's hidden folder is used, and Google sees only encrypted data.

      Create an OAuth client of type “Desktop app” in Google Cloud Console (enable the Google Drive API first), then paste its ID and secret here.

      Recovery phrase

      These 24 words are the space key. Anyone with them can read your space; without them, losing every device loses the data. Write them down and keep them somewhere safe.

      Backups

      A backup holds every plugin's data and the plugin list, encrypted with the recovery phrase. Restoring merges it in: newer changes are kept.
